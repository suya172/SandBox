# TERRA-WEAVE

ブラウザ上で動作する、`256 × 144` グリッドのセルオートマトン物理と生態系・電力オートメーションを組み合わせた2Dサンドボックスゲームです。ランタイムの外部ライブラリを使用せず、TypeScript と HTML5 Canvas 2D、Web Audio API で実装されています。

公開URL: https://suya172.github.io/SandBox/

## 主な機能

- 前景（物理・化学・回路）と背景（支柱・太鼓橋アーチ・羽根車ブレード・装飾）の二層 `TypedArray` グリッドによるセルオートマトン演算（水循環、水と溶岩からの黒曜石生成、砂のガラス化、湿潤土での植物成長）
- 地形に応じたプロシージャル建築（水面や谷をまたぐ木材配置での太鼓橋・背景支柱生成、木材十字の中心への銅線配置による羽根車発電機の生成）
- 銅線・蓄電池・環境センサー・自動ゲート・電動ポンプ・パイプによる送電および流体輸送
- 環境条件から自然発生し、灌漑・消火・資源運搬・電荷供給を行う3種の自律スプライト（モフみず、コロねっこ、ピカリん）
- 自由配置の `Cozy Toy` モードと、中央のテラリウム・コアへ5段階の資源・電力を納品して要素を解放する `Alchemist` モード、および気象イベント（雨季、熱波、流星群）
- RLE + Base64 による `#world=...` URL共有、PNG `tEXt` チャンクへのワールドデータ埋め込み保存とドラッグ＆ドロップ復元、矩形範囲のブループリント登録・スタンプ配置
- Web Audio API によるプロシージャル効果音・環境音合成と、日本語 / 英語の表示切替

## 操作方法

- 左クリック / ドラッグ: 選択中のマテリアルの配置（ブループリント選択時はスタンプ配置、範囲登録時は矩形選択）
- 右クリック / ドラッグ: 前景セルの消去
- マウスホイール: 表示倍率の変更（1.0倍〜4.0倍）
- 中ボタンドラッグ、または `Space` + 左ドラッグ: 拡大時の表示位置移動
- PNGファイルのドラッグ＆ドロップ: スナップショットPNGに埋め込まれたワールドデータの読み込み
- `Escape`: モーダルダイアログを閉じる

## 開発とビルド

Node.js 環境で依存関係を導入し、開発サーバーを起動します。

```bash
npm install
npm run dev
```

利用可能なスクリプト（`package.json`）:

- `npm run dev`: Vite 開発サーバーの起動
- `npm run typecheck`: TypeScript の型チェック（`tsc --noEmit`）
- `npm test`: Vitest による単体テストの実行（`vitest run`）
- `npm run build`: 型チェックと `dist/` への本番ビルド
- `npm run preview`: ビルド済み成果物のローカルプレビュー

## ディレクトリ構成

- `src/core/`: 二層グリッド（`WorldGrid`）、マテリアル定義、セルオートマトン物理演算、シード地形生成
- `src/systems/`: 太鼓橋・環境装飾のプロシージャル生成、発電・送電・ポンプ・センサー回路
- `src/entities/`: 自律スプライト3種のスポーン判定、状態遷移、描画
- `src/modes/`: `Alchemist` モードの進行管理と気象イベント制御
- `src/render/`: `Uint32Array` ピクセルレンダラーと低解像度グローライティング合成
- `src/audio/`: Web Audio API によるプロシージャル音響合成
- `src/ugc/`: ワールドデータのシリアライズ、PNG `tEXt` チャンク埋め込み・抽出、ブループリント管理
- `src/ui/`, `src/styles/`: HUD、観測サイドバー、マテリアルパレット、多言語辞書、スタイル定義
- `tests/`: 物理反応、建築・電力回路、スプライトAI、UGC・進行管理の単体テスト
